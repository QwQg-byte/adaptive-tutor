## 五、MC0577 公式显示修复

### 问题

本批新题保留了合法 TeX 定界符，例如：

```text
$$AbC$$改成$$abc$$），改过后的密语记作$$s$$。
```

旧版前端仅处理历史数据中被拍平的公式，没有识别新数据中的显式 `$$...$$`，因此题目
面板将定界符直接显示出来。

### 修复

- 在 `application/frontend/src/utils/questionMathText.js` 中增加显式数学片段识别。
- 先将配对的 `$$...$$` 转为内部数学片段，再执行旧题公式重建，最后交给 KaTeX 渲染。
- 不修改 JSON 或 Neo4j 中的原始题面；`$$` 是正确的 TeX 数据，问题只存在于前端渲染层。
- 新增 `questionMathText.test.js` 和 `useSafeMarkdown.test.js` 回归用例。

实际 Edge 浏览器验证 MC0577 详情面板：

- HTML 和可见文本中均无字面量 `$$`。
- `AbC`、`abc` 和 `s` 正常显示。
- 页面共渲染 9 处 KaTeX 内容。
- 题目标题“燕丹归国谋策”正常显示。
